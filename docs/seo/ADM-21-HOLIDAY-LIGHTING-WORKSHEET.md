## Default working agreement

Unless changed in the answers above:

- Research and audits remain read-only.
- Observations, inferences, and recommendations will be separated.
- Existing URLs will be preserved unless evidence supports a separately approved change.
- No location-page expansion will occur solely because a competitor has more pages.

- Every implementation step will be presented for approval before code or content is changed.
- Each approved change will receive validation and an appropriate measurement window.
